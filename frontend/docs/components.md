# Components

Shared components:

- `Logo`: SVG-backed NurseKonnect brand.
- `TopNavigation`, `Sidebar`, `MobileNavigation`, `Footer`: consistent navigation surfaces.
- `PageHeader`: page title, description, and actions.
- `EmptyState`: professional empty-state pattern.
- `LoadingState`: static skeleton-card pattern.
- `Button`, `Card`, `Badge`, `Input`, `Label`, `Skeleton`: shadcn-style primitives.

Cards use borders, small radii, clear spacing, and low-shadow treatment. No animation-specific components are used.
